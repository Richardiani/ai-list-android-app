# AI List Android App

A simple Android app built with Kotlin and Jetpack Compose that stores tasks locally using Room. It includes:

- Add new tasks
- Search and filter by category
- Smart suggestion chips
- Mark tasks complete
- Delete tasks
- Local storage with Room database

## Tech stack

- Kotlin
- Jetpack Compose
- Room
- Android Studio

## Run it

1. Open the project in Android Studio.
2. Let Gradle sync.
3. Run the app on an emulator or physical device.

## Project structure

- `app/src/main/java/com/example/ailist/MainActivity.kt`
- `app/src/main/java/com/example/ailist/data/` - Room database and repository
- `app/src/main/java/com/example/ailist/ui/` - Compose UI and ViewModel
